Meu Controle Financeiro v2.0
Abra index.html em hospedagem HTTPS para instalar como PWA.
Recursos: lançamentos editáveis, categorias, vencimentos, contas, orçamentos, metas, filtros, relatórios, CSV e backup JSON.
Os dados ficam no armazenamento local do navegador; exporte backups periodicamente.
Para atualizar, substitua todos os arquivos no mesmo endereço do app anterior.
